深度范围（仅"仅影响发给AI的内容"时才有意义，留空＝不限制）：
💡 "深度"是距离最新一条消息多少条（最新=0，越往前越大）。比如只想隐藏5条以前的旧历史给AI省token、又不想影响最近几条，最小深度填5、最大深度留空即可——跟酒馆自己的正则脚本"深度限定"是同一个概念，从酒馆导入的脚本会自动带上这两个值。
不少接自定义/中转API的模型会把完整思考过程直接堆在正文最前面（用各种标签包一层，不同预设/模型约定的标签名都不一样）。这里可以配置识别哪些"前缀+后缀"组合当作思维链。思维链只在「小说」和「续写」里可以展开查看（跟酒馆一样），聊天、评论、推文、论坛这些地方一律直接剥掉不显示——因为折叠框会拼在正文最前面，把角色卡状态栏那种从开头锚定匹配的正则挡住，导致状态栏出不来。下面这个选项只影响小说和续写。只会在文本最开头匹配，不会误伤正文中间偶然出现的同名标签；没有闭合标签的思维链无法安全识别，会原样保留。
💡 "记忆召回面板/记忆库管理"、聊天总结、推文记忆总结、向量记忆浏览与开关/模型/字数上限这些"跟记忆有关"的设置和展示功能，已经全部搬到独立的新页面「🧠 记忆总览」集中管理去了（侧边栏可以直接进，不用再从设置这里找）。这里只留正则脚本/思维链这些配置项。

🔌 插件
插件是可以导入/导出、分享给别人使用的"打包好的功能"，不用每次都改代码。支持四种类型：提示词规则（往AI脑子里塞一条固定指令）、快捷动作（聊天框上方加一个按钮，点一下发送预设指令，比如掷骰子）、宏（扩展 {{xxx}} 占位符）、脚本钩子（进阶，自定义JS，请只导入信任来源的脚本）。
💡 想导入 SillyTavern 的"Chat Completion 预设"？现在有了专门的「预设」页面（仿酒馆预设管理界面：可整体导入/切换/拖拽排序/导出），去左侧导航栏「预设」里操作。

新建插件

⚠️ 进阶功能：这段代码会被直接执行。只导入你信任来源的脚本！
函数签名：function(char, context, applyMacros) { return "要注入的文本"; }
函数签名：function(char, sessionId, response, applyMacros) { ... }，response是AI返回的JSON对象，可以直接读取/修改它的字段（比如 response.affinityDelta、response.replies），全局变量（myCharacters、saveAllData、showToast等）都能直接用。
函数签名：function(applyMacros) { ... }，这段代码会在每次打开网页、数据读取完毕后自动跑一次，document/window/全部页面里的函数和变量都能直接用，可以用来注入自定义的导航按钮、页面、弹窗、样式等。
