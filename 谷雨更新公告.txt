· 观影口味：可以手写，也可以让角色自己写
· 片库搜索、上一部 / 下一部
· 统计可以清零

【🎬 新功能：一起看电影】
入口：设置 → 🧩 小功能 → 一起看电影。是一整个页面，不是悬浮窗。
· 打开本地视频文件。视频本身不存进来，只记片名、封面、字幕、看到哪儿、说过的话
· 电脑上会记住文件，下次一键接着看；手机上重选一次文件，进度和评论都还在
· 导入字幕（srt / vtt / ass），角色靠字幕"看懂"剧情，每隔几分钟自己判断有没有想说的，没有就不说
· 没字幕 = 纯陪看，一次 API 都不调
· 可切全屏，全屏时角色的话变成弹幕飘过去（速度、字号、透明度可调，也能关）
· 悬浮聊天窗：能拖、能缩放、位置大小记住，全屏时也在
· 进度条上标着每条评论的位置，点一下跳过去
· 五种皮肤：午夜场 / 放映厅 / 录像带 / 胶片 / 素白
· 一起看了多久、看了几部有统计；看完能让角色写观后感，以后聊天会提起

【一起阅读：侧栏和手机抽屉的入口删了】
统一走 设置 → 🧩 小功能。

【修复】
· 「一起看电影」页面会和主页时间线叠在一起显示（核心 switchMainView 里没有这一页的分支，
  走到了"谁都没显示就退回主页"的兜底，之后页面又被显示出来，于是两个都在）
· 「+」悬浮发帖按钮在看电影页也飘着

· 身上的状态会累积 —— 本地推算累/困/饿/上头/刚运动完
