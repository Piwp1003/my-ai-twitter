# 📱 手机 MCP：不做插件、不重新打包，让 TA 用上你的手机

以前「真手机」那些本事要靠「谷雨守护」原生插件 + HBuilderX 云打包，又麻烦又不一定打得进去。
这个是另一条路：**在手机上开一个小 MCP 服务器**，谷雨「🧰 我的 MCP」去连它。

- **不用改 APK、不用插件、不用重新打包**：现在装着的谷雨 App 直接能连
- 手机浏览器里开的网页版也能连（服务器开了跨域）
- 桌面版也能连（服务器加 `--host 0.0.0.0`，同一个 Wi-Fi 下用手机的局域网 IP）

## TA 能干什么

| 工具 | 干嘛 |
|---|---|
| now / battery / wifi / location | 现在几点、电量、连的哪个 Wi-Fi、大概在哪 |
| notifications | 读你手机上的通知（谁给你发了消息） |
| notify / toast / vibrate | 给你弹通知、弹小字、震一下 |
| remind_later | 过几分钟弹提醒（喝水、睡觉、起床） |
| speak | 用手机念出来 |
| torch / volume / brightness | 手电筒、音量、亮度 |
| clipboard_get / clipboard_set | 看你复制了什么 / 帮你复制一段字 |
| call_log / sms_list | 看最近通话、短信 |
| open_url | 在你手机上打开网址 |
| sms_send / phone_call | 发短信、打电话（**默认没开**，要 `--danger`） |

在「🧰 我的 MCP」里点进这台服务器，每个工具都能单独关。

## 装（一次就好，大概 5 分钟）

1. 从 **F-Droid** 装这两个 App（**一定要同一个来源**，Play 商店版的 Termux 太老了）：
   - **Termux**
   - **Termux:API**
   - （可选）**Termux:Boot**：想开机自己启动就装
2. 打开 Termux，粘这一行回车：
   ```
   curl -fsSL https://cdn.jsdelivr.net/gh/Piwp1003/my-ai-twitter@main/phone-mcp/install.sh | bash
   ```
   （jsdelivr 不通的话把网址换成
   `https://raw.githubusercontent.com/Piwp1003/my-ai-twitter/main/phone-mcp/install.sh`；
   都不通就把 `guyu_phone_mcp.py` 拷到手机上，在 Termux 里 `pkg install python termux-api` 后
   `python 文件路径` 直接跑。）
3. 装完敲 `guyu-phone` 回车，会显示一串**口令**，记下来。
4. 打开谷雨 →「🧰 我的 MCP」→ 点 **📱 接上这台手机** → 把口令粘进去 → 自动测试连接。
5. 记得打开「我的 MCP」总开关。

## 权限（用到哪个开哪个）

系统设置 → 应用 → **Termux:API** → 权限：位置、短信、通话记录、电话按需打开。
读通知要单独开：设置 → 通知使用权（或「特殊应用权限 → 通知读取」）→ 打开 Termux:API。
改亮度要：设置 → 修改系统设置 → 允许 Termux:API。

## 让它别被杀

- Termux 的通知栏里点 **Acquire wakelock**（`guyu-phone` 已经自动申请了）
- 系统设置里把 Termux 的电池优化关掉、允许后台运行 / 自启动
- 装了 Termux:Boot 的话，开机后它会自己起来（打开一次 Termux:Boot 让它生效）

## 连不上看这里

| 现象 | 怎么办 |
|---|---|
| 测试连接说「密钥不对」 | 口令填错了。Termux 里 `cat ~/.guyu_phone_mcp_token` 看口令 |
| 连不上 / Failed to fetch | Termux 里那个窗口是不是关了？重新敲 `guyu-phone` |
| App 里连不上、浏览器里能连 | 少数打包设置不允许 http 明文请求：HBuilderX 的 manifest.json →「App 常用其它设置」里允许 http |
| 工具报「找不到 termux-xxx」 | `pkg install termux-api`，并且装好 Termux:API 这个 App |
| 工具一直没反应 / 超时 | Termux:API 没给对应权限；或者 Termux 和 Termux:API 不是同一个来源装的 |

## 安全

- 服务器默认只听 `127.0.0.1`，同一台手机上的程序才能连。
- 有口令：手机上别的网页也能访问 127.0.0.1，没口令的话它们就能读你的短信和通知。
- 发短信 / 打电话默认关着。真要开：`guyu-phone --danger`。
