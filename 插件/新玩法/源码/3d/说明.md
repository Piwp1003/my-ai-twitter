# 🧊 3D 小人引擎（js/vendor/gy3d.min.js 的源码）

- `engine.js` 小人（动作 / 表情 / 口型）、单人小舞台 Stage、3D 小屋 Room、各种模型的加载（VRM / GLB / FBX / PMX）
- `chibi.js` 内置捏人：画布画 Q 版小人（正面、背面、每块属于哪个部位）
- `lowpoly.js` 低模小人（照 lowpoly.kkeist.com「低模小人建造师」的做法）：256 格方形画布、每格一个部位；描轮廓→抽稀→Delaunay 三角化→抱枕形厚度（中间平、边上按圆润度圆过去）→正反面+侧面；手脚往身体里伸 4 格不露缝；自己的着色器（柔光+边缘暗+暖色）
- `hair.js` 21 种发型（发帽 / 刘海 / 鬓发 / 后发 / 马尾 / 丸子 / 麻花辫……）
- `doll.js` 任意图片 → 抠背景、放进方格、自动分 头/头发/身体/手/脚、自动做背面
- `pic.js` 老版的图片变 3D（现在只剩抠背景等工具函数）
- `mii.js` 🙂「朋友收集」风：大圆头 + 胶囊身子 + 短手脚，按捏人选项直接用几何体搭（不走图片鼓起来）；脸画在一张图上投到头上，表情 / 说话换这张图；头发是一顶「发帽」——每个方位一列，从头顶铺到发际线（前面刘海、两边鬓角、后面后脑），长发从那圈直直垂下来，边缘是平滑的线；马尾 / 双马尾是沿弯线扫出来的发束。身高 / 胖瘦 / 头大小三个滑块
- `skel.js` 🦴 骨架：15 个关节（头、脖子、胯、左右肩肘手、左右胯膝脚；左 = 角色自己的左 = 图上右）。`skelAuto` 从轮廓找（头 = 上面最大内切圆；手 = 不连着脸的肤色小块，找不到用「从脖子走最远的尖」；脚 = 最下面一条里最大的两段）；`labelsFromSkel` 按「沿着身上走、离哪根骨头最近」分部位（跨描线 / 颜色突变算远，所以分界贴着描线），头顶颜色连着往下走的算头发；`skelRig` 给建模用：关节转轴 + 把举着的手 / 分开的腿掰回下垂要转多少；`skelPosed` 判断是不是摆了动作的图（有手脚要掰 35° 以上）

依赖 three@0.164.1、@pixiv/three-vrm@2.1.3（这个版本的 three 还带 MMDLoader，再新就没了）。

改完重新打包（在这个文件夹里）：

```
npm i three@0.164.1 @pixiv/three-vrm@2.1.3 delaunator@5.0.1 cdt2d@1.0.0 esbuild
npx esbuild engine.js --bundle --format=iife --global-name=GY3D --minify --legal-comments=none --outfile=../../../../js/vendor/gy3d.min.js
```

改了引擎记得把 `136-3D小人.js` 里 `gy3d.min.js?v=9` 的数字 +1（让手机 / 网页拿新的）。
`js/vendor/gy3d-pet.html` 是桌面版 exe 里电脑桌面上那个 3D 小 TA 的窗口。
