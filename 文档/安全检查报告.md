# 谷雨 代码安全检查报告（2026-10-27）

## 7. 插件 / 本体里有没有引用第三方现成代码
有，但都是正规、知名的开源库，而且是**放在本地** `js/vendor/` 里（不是从外部 CDN 临时加载的），可控：

- `js/vendor/jquery.min.js`（jQuery，做页面时用）
- `js/vendor/localforage.min.js`（本地存储，存聊天记录/数据）
- `js/vendor/mammoth.browser.min.js`（读 Word .docx 文件用）
- `js/vendor/ejs.min.js`（人设/世界书里的 `<% %>` 模板）

这些都是 MIT/Apache 这类宽松开源协议，放心用。
你写的那些「新玩法」「软件」插件本身是**你自己的代码**，没有夹带别人的来路不明的代码。

另外，联网搜索/找资源的功能（`js/29`、`js/59`）会借用几个**公共 CORS 代理**（codetabs、allorigins、corsproxy.io、cors.lol）来帮忙抓网页。注意：经过这些代理的网址和网页内容，代理方是看得到的——但只是公开网页，**不涉及任何密钥**。介意的话可以在那两处关掉代理、只留直连。

## 8. 跑代码用了哪些云平台？railway / zeabur 被攻破有没有影响？
**没有影响。** 这个项目**从头到尾没有用过 railway，也没有用过 zeabur**（全仓库搜不到任何相关痕迹）。

项目真正用到的「云」只有三处：
1. **Cloudflare Workers**（`worker.js`）——做「角色主动给你发消息/发推」的定时检查，10 分钟一次。
2. **GitHub Actions**（`.github/workflows/apk.yml`）——在 GitHub 上帮你打 APK 安装包。
3. **GitHub Pages / Cloudflare Pages**——放静态网页（白露那套也是）。

AI 模型的调用是**从你的手机/浏览器直接发给你选的模型服务商**（DeepSeek / OpenAI / 硅基流动 / OpenRouter / Google 等，你在设置里填哪个就用哪个）。

所以就算 railway、zeabur 出了安全事件，**跟谷雨无关**，不用担心。（如果你在别的项目里用过这两个平台，那边的密钥该换还是要换，但谷雨这个仓库不受影响。）

## 9. 代码安全隐患 / API key 密钥泄露风险
**好消息：现在的代码里、以及 git 历史里，都没有发现写死的 API key 或密钥。** 密钥处理方式是对的：

- Cloudflare Worker 的密钥（AUTH_TOKEN、个推 AppKey/MasterSecret）走 Cloudflare 的 env/KV，**不在代码里**。
- AI 的 key 存在你自己浏览器的本地存储里，用的时候才发给模型服务商。

**需要你知道的一个点（不是 bug，是设计取舍）：**
当你开了「云端主动消息」（填了 Worker 地址 + 授权口令）后，为了让服务器能替角色定时生成消息，你的 **AI key 会被同步到 Cloudflare 的 KV 里存着**（`worker.js` 用它调模型）。这意味着：
- 这个功能**没开**的话，key 只在你手机本地，没上云。
- 开了的话，**你的 Cloudflare 账号安全 = 你 AI key 的安全**。建议：Cloudflare 账号开两步验证；AUTH_TOKEN 设长一点；万一 Cloudflare 账号出问题，去模型服务商那边把 key 重置一次就行。

## 10. gitignore 已加好「禁止上传密钥/配置」
`.gitignore` 里原本就挡了签名密钥（`*.jks`/`*.keystore`）、node_modules、本地数据、备份。
这次又补了一段，把这些也挡在外面，上传 GitHub 不会带上去：
`.env` / `.env.*` / `.dev.vars`（Cloudflare 本地密钥）/ `.wrangler/` / `*.local` / `*.secret.json` / `密钥.txt` / `私密配置.*`

以后你本地的密钥、私密配置，只要用上面这些名字（比如把 Worker 的口令写进 `.dev.vars`），就永远不会被传上去。
