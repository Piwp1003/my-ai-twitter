谷雨 · 好感度到底是怎么算的
（v106 · 2026-09-08）


════════════════════════════════
一句话
════════════════════════════════

好感度 = 你手动设的**基准分** + 账本上每一笔加减的**总和**，
夹在 −100 ~ +100 之间，再按你自己定的**阶段表**翻译成「陌生 / 熟人 / 朋友 / …」。

角色看到的**默认不是数字**，是那个阶段名 + 最近发生的那几件事。


════════════════════════════════
一、以前是什么样（为什么要改）
════════════════════════════════

老的好感度就是 char.affinity 一个数字。问题是：
  · 涨了跌了都不知道为什么
  · 角色自己也用不上它——它没进 prompt，TA 不知道你们熟到哪一步
  · 你想调只能改存档

所以做了「💗 关系账本」（小功能 → 关系账本），把它变成一本带原因的流水账。


════════════════════════════════
二、现在的数据长什么样
════════════════════════════════

存在单独的库 gyRelBox 里（不进主存档）：

  S.base[角色id]  = 基准分
        你在关系账本里点「直接设成」时写的。默认没有（= 0）。

  S.led[角色id]   = [ {id, at, d, why, src}, ... ]   ← 流水账
        d    这一笔加减多少（−20 ~ +20）
        why  为什么（不超过 50 字）
        src  这一笔哪来的：手动 / 情绪 / 聊天 / 事件 / 外部

  总分 = clamp(base + Σd, −100, 100)

分成两截是为了让「自定义好感度」和「流水账」不打架：
你把它设成 60 之后，后面自动记的那些笔照样在 60 上面加加减减，
而不是把你设的数字冲掉。

  S.stages = 阶段表，默认六档，可以自己改名字和分数线：
        −60 敌意 / −20 疏远 / 0 陌生 / 20 熟人 / 50 朋友 / 80 亲近
        （具体默认值以功能页里显示的为准，你可以随便改）


════════════════════════════════
三、分数从哪来（四个来源，可以同时开）
════════════════════════════════

① 跟着「情绪惯性」走          零成本，推荐
   活人感里的「情绪会留到下一轮」每轮回复已经带出 mood 和 moodWhy 了。
   账本盯着它变没变，变了就折一笔进来（−5~5 折成 ±2.5）。
   **一个字都不多发**——它是蹭已有字段。
   ⚠️ 前提：设置 → 🫀 活人感 →「情绪会留到下一轮」要开着，
      不开的话这一项收不到任何东西（功能页里现在会直接提示这一条）。

② 让模型每轮单独给一个数      每轮多两个字段
   在聊天那一轮的 JSON 里多要 rel（−5~5）和 relWhy（15 字以内）。
   拿到之后折半记账（rel÷2），所以单轮不会让关系跳档。
   prompt 里明确写了"只有聊天那一轮才加，写推文/日记/信件/小说绝对不要加"，
   防止数字混进正文。

③ 一起听歌 / 一起出去，自动记账   纯本地读，不调 API
   读音乐盒和行程与天气的存档：
     一起出去成了      +2.5（超过两小时 +4）
     约了没约成        −1.5
     一起听歌每满一小时 +1
   按记录 id 去重，同一件事不会记两遍。

④ 你自己手动记一笔 / 直接设成一个数
   完全免费。


════════════════════════════════
四、它怎么影响角色（也就是"联动"到底联的是什么）
════════════════════════════════

这才是关键。账本会往**每一次拼 prompt** 里注入这么一段：

    【你对林的感觉】：现在是「朋友」。
    最近让它变成这样的事：
    · 今天　拉近了一点　她记得我不吃香菜
    · 3 天前　推远了一点　我说的话被当成玩笑
    这不是让你报数字或者演一个等级——是让你知道你们走到哪一步了、以及为什么。
    你的语气、边界感、主动程度、愿不愿意示弱，都该跟这个阶段对得上；
    上面那些事是真发生过的，提到的时候你是真的记得。
    关系不会因为这一轮就跳档，也不会无缘无故升温。

注意三件事：
  · **默认不报数字**，只给阶段名 + 最近几件事
    （想要数值恋爱游戏那种感觉，就在功能页里打开「把分数本身也告诉角色」）
  · 注入几条你可以调（默认 6 条）
  · 走的是全 app 统一那条注入管道（js/06 的 getBoxPrompt），
    跟音乐盒、随身物、日子那些是同一批，不会重复也不会漏

另外还有一个可选的联动：
  · **同步到主程序的好感度系统**
    打开之后把总分写进 char.affinity 并打开 enableAffinitySystem，
    这样「势力关系网」页上的 💗 徽章和连线粗细会跟着动。
    不打开的话账本自己玩自己的，不碰主存档。


════════════════════════════════
五、总开关
════════════════════════════════

设置 → ⚙️ 自动化功能 → 🫀 活人感 →「关系账本：用不用这套好感度」

关掉之后：
  · 不再往任何 prompt 里注入一个字
  · 不再自动记账
  · 已经记下的流水**不会删**，随时开回来还在

（记账本身不额外调 API——它蹭的是已有回复里的字段。
  唯一会多花的是"让模型每轮单独给一个数"那一项，也只是多两个输出字段。）


════════════════════════════════
六、你想怎么调，在哪儿调
════════════════════════════════

小功能 → 💗 关系账本
  · 「往来」页：每个角色一行，点开能看流水、手动记一笔、
     直接把好感度设成任意数字、清掉基准、清空这个人的账
  · 「怎么记账」页：四个来源的开关、要不要报数字、
     要不要同步到主程序的好感度系统
  · 「阶段」页：改阶段名和分数线
  · 「预览」页：选一个角色，直接看现在会往 prompt 里注入什么
