════════════════════════════════
一、四类接口
════════════════════════════════

  ① 主 API      好模型。写你会逐字读的东西。
  ② 副 API      便宜模型（选填）。后台杂活、插件、小游戏。
                地址 + 密钥 + 模型三样没填全 → 全部退回主 API，一切照常。
  ③ 向量 API    只做 embedding（选填）。没填用主 API 的地址；永远不碰副 API。
  ④ 语音 / 生图  各自在自己的设置里填，跟上面三个无关；都有不花钱的退路。

代码里怎么取：
    getApiMain()          主的优先；主的没配全 → 退到副的
    getApiConfig(false)   只用主的
    getApiConfig(true)    副的优先；副的没配全 → 退到主的
    getVectorApiConfig()  向量的；没填 → 主的地址
    插件里的 X.ask()       = getApiConfig(true)，副优先

五、不是聊天模型的接口
════════════════════════════════

向量（embedding）
  · 向量记忆、资料库检索 → 向量 API（没填用主 API 地址），模型名在设置里填（默认 text-embedding-3-small）

生图（js/42 角色发图；TA 的相册 / 自拍 / 情侣头像都走这里）
  · 图库 / 搜图：不花钱
  · 调接口生图：你填的画图接口（/v1/images/generations）
  · 免费退路：image.pollinations.ai

语音（js/76 TA 的声音、js/47 通话）
  · 朗读：OpenAI 兼容（/v1/audio/speech）、MiniMax、Fish Audio、火山引擎；浏览器自带朗读不花钱
  · 你说话转文字：SiliconFlow 等转写接口（/v1/audio/transcriptions），或浏览器自带识别

只联网、不用模型（都免费）
  · 天气、城市：Open-Meteo（js/23）
  · 联网探索：r.jina.ai 阅读、DuckDuckGo、维基百科，经公共 CORS 代理（js/29）
  · 在线找书 / 歌 / 片：Gutendex、维基文库、Internet Archive、iTunes 搜索（js/59）
  · 🔥 真实热搜：60s.viki.moe、api-hot.imsyy.top、api.pearktrue.cn（插件 90，可以自己换接口）
  · 🔄 插件自动检查更新：读你自己网站上的「插件/新玩法/新玩法全家桶.json」（js/95）
  · 云端推送：你自己部署的 Cloudflare Worker（js/07、worker.js）
  · 从 GitHub 导入世界书：raw.githubusercontent.com（js/12）

七、想省钱
════════════════════════════════

  · 填一个便宜的副 API：杂活、插件、小游戏都不占主 API
  · 设置 → 全部开关：每一项都写了「费用」，用不上的关掉
  · 插件开关中心：只关「TA 会自己做」，你自己照样能玩，TA 不会主动花钱
  · 🔋 省电模式：后台定时器跑慢一点
  · 设置页最上面「📊 Token 用量」：每个功能各花了多少，一目了然
