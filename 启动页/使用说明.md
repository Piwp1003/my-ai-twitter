# 谷雨 · 安卓启动图

给 HBuilderX 打包 APK 用的启动页图片，已按 DCloud 官方 manifest.json 规格生成。

原图是 3:4 的方形构图，手机启动图是 9:19 左右的细长比例——直接拉伸会把伞压扁，
所以统一做成「白底 + 等比缩放居中」。原图本来就是白底线稿，多出来的白边看不出接缝。

## 怎么配（两种选一种）

### 方案 A：.9.png（推荐）

HBuilderX 官方推荐这种，好处是**任何屏幕比例都不会变形**——只有白边被拉伸，
插画本身尺寸永远不变。一张顶上面全部六张。

1. HBuilderX 打开 `manifest.json`
2. 左侧选「App启动界面配置」
3. Android 启动图片那一栏，选择 `.9.png` 方式
4. 传 `splash.9.png`

### 方案 B：固定尺寸图

如果你的 HBuilderX 版本没有 .9.png 选项，就用这套：

1. `manifest.json` →「App启动界面配置」→ Android 启动图片
2. 按密度分别选对应文件：ldpi / mdpi / hdpi / xhdpi / xxhdpi
3. 文档里这五个都标了「必选」，建议都传上，缺了某个密度的机型会拿不到图

## Android 12 及以上要单独配

Android 12 改了启动页机制，系统只显示**中间一个图标 + 一个背景色**，
不再显示整张启动图。所以上面那套在 Android 12+ 机器上不生效，要另外配：

- **背景色**：`#FFFFFF`（跟插画底色一致，不然会露出色差边）
- **中心图标**：`android12-icon.png`

在 `manifest.json` 里找「Android 12及以上启动界面」之类的配置项填进去。

> `android12-icon.png` 是 1152×1152 的画布，图形收在中间 768×768 内——
> 这是 Google 的规范，外圈会被系统裁掉，留出来是防止边缘被切。

## 想重新生成

`make_splash.py` 是生成脚本，跟 `source.jpg` 放一起跑：

```
python make_splash.py
```

想调整画面大小或位置，改 `compose()` 的三个参数：

- `width_ratio` — 插画最多占画布多宽（现在 0.94）
- `height_ratio` — 最多占多高（现在 0.78，防止细长屏上顶天立地）
- `y_anchor` — 画面中心落在高度的百分之几（现在 0.50，正中）

脚本里对 .9.png 的拉伸区做了纯白校验——拉伸线段必须落在「整行/整列都是纯白」
的位置，否则拉伸时会把线条拉糊。改参数后重跑，看输出里那两个「纯白校验」是不是
还是「通过」。
