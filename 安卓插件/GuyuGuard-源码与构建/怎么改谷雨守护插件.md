# 怎么自己改「谷雨守护」原生插件

这个插件是让「📲 真手机」能真的看屏幕时间、截屏、锁软件的那一块（只在安卓 App 里有用）。
平时你**不用动它**——装好一次、云打包一次就行。这份是你想自己加 / 改功能时看的。

## 它由哪几块组成

```
GuyuGuard-源码与构建/
  src/com/guyu/guard/      ← 真正的 Java 代码（你要改的就是这里）
    Guard.java             看屏幕时间、截屏、锁屏、换壁纸、设闹钟…每个本事都是这里的一个静态方法
    GuardAccess.java       无障碍服务：挡被锁的软件（HOME + 把谷雨拉回来）
    GuardNotify.java       通知监听服务：读别的软件的通知
    GuardModule.java       一个空壳（uni 原生模块的入口，没放功能）
  stubs/                   ← 「安卓接口占位」，只为了让电脑能编译，不进插件（手机上用的是系统真货）
  aar/                     ← 插件的外壳：AndroidManifest.xml（权限、服务）、res（无障碍配置、文字）、R.txt
  build.sh                 ← 一键重新打包
  nativeplugins/GuyuGuard/        ← 打包好的成品（package.json + android/GuyuGuard.aar），就是放进 HBuilderX 的那个
```

网页端（js 那边）通过 `plus.android.importClass('com.guyu.guard.Guard')` 调 `Guard.java` 里的方法。
**所以：Java 里加一个方法 → 网页 `60-真手机.js` 里就能调它。** 两边名字对上就行。

## 怎么加一个新本事（举例）

1. 在 `src/com/guyu/guard/Guard.java` 里加一个 `public static` 方法，比如：
   ```java
   // 把手机调成静音
   public static boolean mute(Object ctxObj) {
       Context ctx = (Context) ctxObj;
       AudioManager am = (AudioManager) ctx.getSystemService(Context.AUDIO_SERVICE);
       am.setRingerMode(AudioManager.RINGER_MODE_SILENT);
       return true;
   }
   ```
   （`AudioManager` 这些如果 `stubs/` 里没有对应的占位，编译会报「找不到符号」——照着 `stubs/android/media/AudioManager.java` 的样子补一个占位方法进去就行，占位里随便 return，真正跑的是手机系统。）
2. 要新权限的话，在 `aar/AndroidManifest.xml` 里加一行 `<uses-permission .../>`。
3. 跑 `bash build.sh` 重新打包。
4. 在 `60-真手机.js` 的 `N` 那一段里加一句 `mute: () => c('mute', ctx)`，就能在网页里用了。

## 重新打包（build.sh）

- **要什么**：一个 JDK（Java 8 或更高）。装了 Android Studio 就自带；没有的话单独装个 JDK 也行。
  **不需要**整套 Android SDK——我们用 `stubs/` 里手写的占位骗过编译器，真正的安卓接口在手机系统里。
- **怎么跑**：在这个文件夹里执行
  ```
  bash build.sh
  ```
  （Windows 没有 bash 的话，用 Git Bash，或者 WSL；再不行照着 build.sh 里那三条 `javac / jar / zip` 命令手动敲一遍也一样。）
- 跑完会生成 `GuyuGuard.aar` 并自动放进 `nativeplugins/GuyuGuard/android/`。把 `nativeplugins/GuyuGuard` 这个文件夹丢进 HBuilderX 项目的 `nativeplugins/`，重新**云打包**，装上新包就生效了。

## 想用 Android Studio 正经改（可选）

如果你想要代码补全、真机调试，可以在 Android Studio 里新建一个 Library 模块，把 `src/` 里的 `.java` 拷进去，`AndroidManifest.xml` 和 `res/` 对应放好，让它自己连 Android SDK 编。编出来的 `.aar` 和这里的等价。`stubs/` 那时就不用了（Studio 有真 SDK）。

## 老实提醒

- 5+App 云打包到底会不会把本地原生插件打进去，各个 HBuilderX 版本不太一样。装好后在 **真手机 → 设置** 顶上看有没有「✓ 谷雨守护 1.0.0 装好了」，这是唯一准的自检。
- 改坏了想回到能用的版本：`nativeplugins/GuyuGuard/android/GuyuGuard.aar` 就是现在好用的那一份，git 里也留着。
