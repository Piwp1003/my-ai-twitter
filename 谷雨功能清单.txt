一、社交平台（主界面）
════════════════════════════════

主页时间线
· 角色按各自的发帖频率自动发推文
· 你发推文（可带图）
· 评论、点赞、转发
· 「为你推荐」/「正在关注」两个 tab
· 帖子详情页、标签页、全站搜索

匿名论坛
· 角色用匿名 ID 发帖（anonName）
· 你也能匿名发
· 独立的发帖频率设置

小说论坛
· 角色发长文帖

营销号（小报）
· 独立账号，会跟风转发、评论热闹事件

通知中心
· 角色发帖 / 评论 / 私聊 / 写信都会来通知
· 未读角标

私聊
· 一对一聊天，支持引用消息、分享推文进私信
· 群聊（多角色）
· 打字指示器
· 聊天列表可置顶、可切换视图
· 归档：长按头像「重新开始」时可保留旧对话，之后能翻回去看、一键恢复

信箱
· 你写信寄给角色
· 角色到点自动回信（延迟时间可设）
· 角色主动写信

我的日记
· 你写日记
· 可以选角色"偷看"，角色到点会看到并批注

角色资料页
· 头像、背景、简介、所在地、生日、网站、粉丝数、认证标记
· 各类频率设置（发帖 / 主动聊天 / 写信 / 匿名帖 / 论坛帖）
· 开场白（支持多个）、忙碌自动回复、拍一拍文案
· 待办清单、日程、纪念日日历
· 从酒馆角色卡导入（PNG / JSON）

势力
· 势力关系网（可视化）、势力成员、势力总览
· 一个角色可属于多个势力
· 角色关系（谁跟谁什么关系）

我们的故事
· Ta们在做什么（小剧场：有关系的角色背着你自己演）
· 续写 / 故事（长篇剧情线）

记忆总览
· 各类记忆的集中查看
· 自动总结频率、日程与小剧场保留天数

三、🫀 活人感（设置 → 活人感，五项，默认全关）
════════════════════════════════

· TA 不总是在线 —— 睡觉/忙的时候消息先挂着，忙完一次性回并交代时间差；
  急事豁免词、作息时间、等多久都可调。唯一一个让调用变少的开关
· 情绪会留到下一轮 —— 情绪按小时衰减，吵完架不会下一句就没事人
· 按 TA 自己的打字习惯说话 —— 提取语言指纹，手动提一次永久复用
· 久远的记忆会褪色 —— 记忆按时间分层，角色知道自己记不清
· 身上的状态会累积 —— 累/困/饿/上头/刚运动完，纯本地推算

另有「🔗 补齐没接上的数据」五项（默认全开，一次 API 都不调）：
· 角色知道自己资料页写了什么（简介/所在地/网站/生日）
· 角色知道自己属于哪个势力、同一边还有谁
· 角色记得自己写过的日记
· 忙碌自动回复真的会发出去
· 角色知道今天是你记在日历里的什么日子

四、🎮 小游戏（聊天输入框上方的图标，11 个）
════════════════════════════════

私聊就能玩：
· 五子棋（15×15，角色自己落子、会认输、会点评）
· 拼大小、21 点、接龙
· UNO（正版 108 张，含万能牌/+2/+4/禁止/反转）
· 昆特牌（近战/远程/攻城三排，三局两胜，含天气/军号/灼烧/诱饵/密探）
· 20 个问题（角色心里想一个答案，你问是非题猜）
· 真心话大冒险（轮流出题，角色会真的完成挑战并描述）

要群聊（人数不够会提示）：
· 斗地主（要 2 个角色，支持单/对/三/三带一/三带二/顺子/连对/飞机/炸弹/火箭）
· 谁是卧底（要 2 个角色，AI 现生成词对）
· 狼人杀（要 3 个角色，村民/狼人/预言家，夜晚行动+白天发言+投票）

通用：
· 邀请时角色按人设决定答不答应
· 悬浮窗可拖动，边玩边聊天
· 结束后角色说一句感言（受「小游戏中角色发言」总开关控制）


════════════════════════════════
五、🧩 小功能（设置 → 小功能，9 个，全部内置）
════════════════════════════════

🎵 音乐盒
· 悬浮播放器，导入本地音频，改歌名/歌手/封面
· 歌单（多个列表）、曲库管理、快速搜索、推荐位、循环模式
· 导入 lrc 歌词，跟唱高亮
· 17 种皮肤（6 大类）
· 邀请角色一起听（可多人）；换歌时说一句 / 唱到某句接一句 / 一首听完给感想（各自开关）
· 让 TA 点一首、主动问 TA 一句、第二个人自己决定接不接话
· 音乐口味（手写或让 TA 自己写）
· 一起听的时长/首数统计、可清零
· 一起听的记忆总结，会进 prompt

🎬 一起看电影
· 页面形态，不是悬浮窗
· 打开本地视频（视频本身不存，只记片名/封面/字幕/进度/评论/对话）
· 电脑上记住文件，下次一键接着看；手机上重选文件，进度评论都在
· 导入字幕 srt / vtt / ass，角色靠字幕看懂剧情
· 没字幕 = 纯陪看，一次 API 都不调
· 全屏 + 弹幕（速度/字号/透明度可调，可关）
· 悬浮聊天窗，能拖能缩放，位置大小记住
· 进度条上标着每条评论，点一下跳过去
· 5 种皮肤：午夜场 / 放映厅 / 录像带 / 胶片 / 素白
· 邀请一起看（角色可拒绝）、结束一起看、问问 TA、让 TA 挑一部
· 观影口味、片库搜索、上一部/下一部、统计可清零
· 从画面截一帧当封面
· 看完写观后感，存进角色，聊天时会提起

📖 一起阅读
· 导入 txt / docx / pdf / epub，自动按章节拆分
· 角色自己判断哪句值得说，评论显示在原文对应句子下面
· 选中原文引用讨论、点评论下方「讨论这条」
· 可全屏、可收起成一条标题栏
· 写读后感，存进角色，聊天时会提起
（pdf 和 epub 需要联网加载解析库，txt/docx 完全离线）

🗺️ 行程与天气
· 17 种悬浮窗皮肤、6 个大类，其中一类同时显示你和角色的 IP 属地与天气
· 地图按人设 + 世界书自动生成，或上传图片自动识别地点标点
· 标点分类可自定义、点击筛选
· 一个势力挂多张地图，跨势力可共享
· 多角色时各回各的所在地，不硬塞进一张图
· 互相邀约：去哪儿、待多久、干什么，事后进记忆总览

💗 关系账本
· 好感度可视化，每次变动都记原因
· 三种来源：情绪推断 / 直接问模型 / 事件
· 9 个关系阶段，名称和阈值都可改
· 同步主程序的 char.affinity

🗣️ 八卦网
· 角色之间传闲话，素材来自小剧场记录和约会行程
· 转述会走样，失真程度三档可调，也可整个关掉
· 你可以去当面对质
· 上帝视角开关：开着时真相先糊着点一下才揭晓

🎒 随身物
· 角色身上带的东西，每样都有来历（谁给的、哪儿来的、什么时候）
· 硬规则：不许凭空掏东西
· 6 种物品状态

📅 日子
· 二十四节气（本地公式算，不联网不花钱）
· 十二时令分层
· 自定义日子 + 提前几天开始惦记
· 读角色日历里手记的纪念日（含周年）

🌐 此刻
· 总览面板：谁在哪、什么心情、在听什么、关系到哪步、身上带着什么、花了多少
· 零 API 调用，纯读本地数据

八、技术特性
════════════════════════════════

· 纯前端，无后端，无账号，不上传
· 数据存本地（IndexedDB），可整包导出备份
· 可直接双击 index.html 打开，也可打包成安卓 APK / 桌面程序
· 断网可用（只有调 AI 时需要网）
· 28 个 js 文件，通过 ?v= 版本号强制清缓存
· 兼容任何 OpenAI 格式的 API
